A modern, responsive, 7-Star luxury boutique hospitality web portal crafted for **Hotel Velora Inn**, situated in Pared Kothi, Cantt, Varanasi (barely 800m from Varanasi Junction Railway Station).

---

## 🌟 Key Highlights & Features

1. **👑 Adaptive Royal Header & Navigation:**
   - Sticky navbar with dynamic scroll color-adaptation matching underlying section themes.
   - Quick access to Rooms, Pilgrimage Map, Gallery, Reviews, FAQs, and Location.

2. **🕉️ Hero Sanctuary & Kashi Slideshow:**
   - Smooth 5-image background transition carousel showcasing Kashi's sacred heritage.
   - Real-time room availability search bar with dynamic stay duration calculations.

3. **🗺️ Sacred Circuit Real-Time Interactive Map Engine:**
   - Powered by Leaflet & Esri World Street Map + Satellite tiles (Zero watermark, 100% reliable uptime).
   - 11 Curated pilgrimage & heritage spots (Kashi Vishwanath Dham, Dashashwamedh Ganga Aarti, Assi Ghat, Kaal Bhairav, Sarnath, etc.).
   - 1-Click Turn-by-Turn Google Maps GPS navigation and pre-filled WhatsApp cab booking.

4. **📸 Filterable Photo Gallery & Lightbox Preview Modal:**
   - Multi-category filter tabs: All Photos, Rooms & Suites, Lobby & Amenities, Kashi Darshan.
   - Built-in full-screen modal preview with keyboard navigation (Arrow keys & Escape) and thumbnail strip.

5. **✍️ Guest Reviews & AI Knowledge-Base Concierge Engine:**
   - Verified traveler testimonials with 5-star ratings.
   - Interactive review submission form with instant knowledge-base suggestions tailored to the guest's rating and stay purpose.
   - Direct escalation to the General Manager for lower ratings or VIP concierge perk unlock for 5-star ratings.

6. **📍 Directions, Proximity Cards & VIP Direct Inquiry:**
   - 100% reliable interactive Leaflet map marking Hotel Velora Inn and Varanasi Cantt Railway Station (800m).
   - Proximity micro-cards to major transit hubs and temples.
   - 7-Star VIP booking inquiry card with room category and guest count selectors linked directly to WhatsApp.

7. **⚡ Instant Direct Concierge Integration:**
   - Direct connection to Front Desk Reception on WhatsApp (`+91 9670215052`) without third-party OTA middleman surcharges.

## 🛠️ Technology Stack

- **Markup & Styling:** HTML5, Semantic Elements, Tailwind CSS (Utility-first styling, CSS animations, custom glow filters)
- **Mapping & GIS:** Leaflet 1.9.4, Esri ArcGIS World Street Map & Satellite Imagery
- **Interactivity:** Vanilla JavaScript (ES6+), DOM APIs, Responsive Touch & Keyboard Listeners
- **Integrations:** Direct WhatsApp Click-to-Chat API, Google Maps Directions API

## 🚀 Quick Start / Local Preview

No complex build steps or dependencies needed! Simply clone and open `index.html` in any web browser:

```bash
# Clone the repository
git clone https://github.com/prabhve/demohotelvelorainnwebsite.git

# Navigate into the project directory
cd demohotelvelorainnwebsite

# Open in browser (Windows)
start index.html

# Or on macOS
open index.html

# Or on Linux
xdg-open index.html
```
